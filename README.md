# UP 数据观察

本机看板监测 [王师傅の日记](https://space.bilibili.com/3546619609876957) 的粉丝数和最近 10 条视频。数据来自本机已连接 Chrome 的 OpenCLI 公开页面采样，保存在本目录的 JSON 快照中；不使用 B 站开放平台。

## 启动

在 PowerShell 中进入本目录后运行：

```powershell
python dashboard.py
```

打开 <http://127.0.0.1:8765/>。服务只监听本机地址。按 `Ctrl+C` 停止。

运行期间，看板按北京时间每天 `00:00 / 06:00 / 12:00 / 18:00` 自动采集，也可点“立即采集”。**关闭服务后不会继续定时采集**。定时任务和手动任务不会并行；采集失败会在看板状态区显示，不会覆盖成功快照。采集时需要 Chrome 可用，且 OpenCLI 浏览器桥接保持连接。

既有样本位于 `samples/`，后续快照位于 `data/snapshots/`。每条视频的增长值是与该视频上一次有效快照的累计值之差，粉丝增长是与上一次账号快照的差；视频第一次进入监测池时显示“暂无对比”。数据缺口按实际采样间隔展示，不补造历史值。

看板默认展示“最近 24 小时”变化，也可切到“最近一次采样”。24 小时窗口从窗口内最早的完整 10 条视频快照开始计算；当历史不足一天时，会显示实际覆盖时长和“未满 24 小时”，不会把较短区间冒充整天。粉丝曲线以基准采样为 0，并按真实采样时间绘制；互动构成和逐次采样变化进一步拆开展示。

单视频趋势区可以按封面或标题切换最近 10 条视频，再切换播放、点赞、投币、收藏、评论、弹幕、分享指标。“区间均速”图用相邻有效快照的增量除以实际间隔小时；“累计值”图按真实采样时间画出已观测点，虚线只辅助阅读。视频表格中的小柱图只比较同一视频各区间的播放均速，点击封面或小图可定位到该视频的完整趋势。封面引用采样得到的 B 站图片地址；地址失效时显示占位图。

当前版本提供总览、粉丝变化、播放增长排行、互动构成、逐次采样记录、单视频趋势、弹幕观察、最近 10 条视频明细与采集状态。视频指标的搜索排序和开机后独立运行的任务计划尚未加入。

## 弹幕观察

“立即采集”会同时更新视频指标与最近 10 条视频的弹幕内容；弹幕区的“采集弹幕”只更新弹幕，方便手动补采。服务运行期间，原有的北京时间 `00:00 / 06:00 / 12:00 / 18:00` 任务也会采集弹幕。首次采集建立历史基线，之后按弹幕 ID 去重，避免重采重复计数。

弹幕原文、发送时间、视频内时间点和首次发现时间仅保存在本机的 `data/danmaku.sqlite3`；不保存发送者标识。弹幕页提供最近 10 条视频热度图、单视频的视频时间/发送时间趋势、热门原句与刷屏反应、热点片段、跨视频共同热梗及原文检索。默认窗口为最近 24 小时；“最近一次采样”需要至少两轮完整弹幕采集。热度图与热门榜单可切换全部已存可读取弹幕或当前窗口。

页面累计弹幕数与本机实际可读取文本数是不同口径：实测可读取数通常较低，不能据此推断具体缺失原因。弹幕页分别展示两者，并标出每条视频的成功分段数。现有视频趋势中的“弹幕”仍是页面展示的累计数；新弹幕页才使用弹幕原文样本。详见[最初的可行性验证](DANMAKU_FEASIBILITY.md)和[看板口径设计](DANMAKU_DASHBOARD_DESIGN.md)。
